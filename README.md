# Vendor Cab & Driver Onboarding - Frontend Demo

A simple React.js + Vite + Tailwind demo covering 3 core features:
1. Multi-Level Vendor Hierarchy
2. Access Delegation to Sub Vendors
3. Vehicle & Driver Onboarding

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Notes

- No backend - all data is mock data seeded into `localStorage` on first load.
- Refresh the page anytime; added vendors/vehicles/drivers/permissions persist.
- To reset to the original mock data, clear your browser's localStorage for this site (DevTools -> Application -> Local Storage -> clear).
